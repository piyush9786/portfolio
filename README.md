# Piyush Shinde — Portfolio

[Visit the live portfolio](https://piyush9786.github.io/portfolio/)

A responsive portfolio showcasing data engineering, applied AI, projects, professional experience, education, and certifications.

## Features

- Interactive portrait with 3D tilt and animated network
- Navy, electric blue, sky blue, and ivory palette
- Filterable projects and highlighted career achievements
- Experience, education, certifications, and downloadable résumé
- Motion controls and reduced-motion support

## Run locally

```sh
python3 -m http.server 8000
```

## Hosting

Hosted free on GitHub Pages. The site publishes automatically from the root of the `main` branch whenever changes are committed.

## Edit the portfolio

Edit `index.html` for content, `style.css` for styling, and `app.js` for interactions. The portrait and résumé files live at the repository root.
